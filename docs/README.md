# docs

ChoTech コミュニティに関する資料です。サイトの文言（About / Activities / Recruit セクション）はここを一次情報としています。

| ファイル | 内容 | 想定読者 |
| --- | --- | --- |
| [about.md](./about.md) | ChoTech の紹介（想い・主な活動・参加対象）。短くまとまった対外向けの説明 | 参加を検討している学生、外部の方 |
| [chotech-community.md](./chotech-community.md) | コンセプト・ビジョンの正式版。設立の想い、活動の柱、サポート制度まで網羅 | 運営メンバー、サイトの文言を編集する人 |

## 更新するとき

- コミュニティの方針や活動内容が変わったら、まず `chotech-community.md` を更新し、必要に応じて `about.md` とサイトのセクション文言を追従させてください。
- 旧名称「TechHive」時代の資料（`concept-and-vision.md`）は `chotech-community.md` に統合済みのため削除しました。必要なら git 履歴から参照できます。
